# Bharat Insurance

Third-party vehicle insurance — Car, Two-Wheeler and Commercial. Static single-page site.

- `index.html` — the app (hero, bento showcase, dedicated vehicle pages via `#/car`, `#/two-wheeler`, `#/commercial`, FAQ, quote/claim/login flows, WhatsApp).
- `#/admin` — passcode-gated dashboard of captured quote requests (stored in `localStorage`).
- `bharat-assets/` — vehicle cutouts, 3D icons, favicon.

Deployed on Vercel.
